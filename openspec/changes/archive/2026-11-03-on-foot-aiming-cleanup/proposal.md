# Proposal

## Why

Дуга прицела головой закрыта: `.40` облетан, `.41` сделал умолчания по полётам (`sync=camera`, `stick_comp=on`,
`pitch_offset=10`). Но в `edvr.ini` и F8 остались временные ключи, которые добавлялись только для подбора в полётах:
зонд, переключатели знака, такта и стика, подобранный угол и ширина HUD. AGENTS.md требует, чтобы после закрытия дуги
удачные значения стали поведением, а лишние ключи ушли. Иначе F8 засорён вариантами, которые больше никому не нужны, а
в коде висят пути, которые никто не проверяет.

Решения Димы (02.11.2026, вопросы с цитатой каждого ключа):
- прицел головой: оставить настройкой `on` / `off`, **включён по умолчанию**, `raw` убрать;
- ведущий глаз `native_vr_on_foot_aim_eye`: оставить настройкой как есть, снять пометку «временный»;
- `..._head_aim_pitch_offset`: удалить, зашить 10°;
- удалить зонд (два ключа и код), три ключа подстройки (`pitch_comp`, `sync`, `stick_comp`) и `native_vr_on_foot_hud_size`.

## What Changes

- **Прицел головой включён по умолчанию.** Ключ `native_vr_on_foot_head_aim` становится постоянной настройкой
  `on` (по умолчанию) / `off`. Значение `raw` (без сглаживания) убирается, старое `raw` в ini читается как `on`
  со строкой в логе. **BREAKING** для тех, у кого ключа нет: раньше прицел был выключен, теперь включён.
- **Удаляются ключи** (с ними пункты F8, разбор, строки «неизвестное значение»):
  - `native_vr_on_foot_head_aim_probe` (`off`/`watch`/`angle1`/`angle2`/`angle1-sway`/`angle2-sway`, сейчас `off`)
    и `native_vr_on_foot_head_aim_probe_compensate` (`off`/`minus`/`plus`, сейчас `off`) — вместе с кодом зонда
    (сдвиги, качание, строки `watch`, сводка зонда) и его стендом `head_aim_probe_test`;
  - `native_vr_on_foot_head_aim_pitch_comp` (`plus`/`minus`/`off`) — навсегда `plus`;
  - `native_vr_on_foot_head_aim_sync` (`latch`/`camera`) — навсегда `camera`;
  - `native_vr_on_foot_head_aim_stick_comp` (`off`/`on`) — навсегда `on`;
  - `native_vr_on_foot_head_aim_pitch_offset` (−30..30, сейчас 10) — навсегда 10°;
  - `native_vr_on_foot_hud_size` (30..110, сейчас 85) — ширина HUD навсегда 85°, меню по-прежнему в долях от неё.
- **Что остаётся от зонда:** проверка байтов кода игры перед хуками и опознание игрока. Прицел головой стоит на тех же
  хуках, поэтому они переходят к фиче. Строки лога меняют префикс `head aim probe:` на `head aim:`.
- `native_vr_on_foot_aim_eye` не меняется по поведению, только описание в ini и комментарии в коде (без «временный»).
- Документ дуги (`## Status`, список ключей) и `ROADMAP.md` (пункт 4) обновляются. В `edvr\README_EDVRONFOOT.md`
  убирается ширина HUD как ключ, добавляется короткий раздел «Прицеливание на ногах» (там его не было; найдено при
  установке `.46`).
- Сборка `.46`: только `d3d11.dll` меняет поведение. Канал с рантаймом (версии 7 и 8) не трогаем, `openvr_api.dll`
  собирается заново без правок поведения.

### Modified Capabilities
- `on-foot-aiming`: ключ прицела головой постоянный, `on`/`off`, по умолчанию `on`. Убираются требования ключей
  знака, такта, стика и зонда, их выбранные значения вписываются в требования поведения («Мир не едет за прицелом»,
  «Поправка наклона ствола» — 10° без ключа). Сглаживание без варианта `raw`. В лог-строки без режима такта.
  Новое требование: проверка кода игры перед хуками прицела головой (раньше было у зонда).
- `on-foot-hud`: ширина листа HUD 85° без ключа. Убираются сценарии смены ширины в требованиях крепления, меню и
  диалогов, меню торговца, магазинов биолога и оружейника.
- `on-foot-head-aim-probe`: все требования удаляются, возможность уходит целиком, как `on-foot-aim-dot-probe` в
  прошлой заявке.

## Impact

- Код: `edvr\src\d3d11\head_aim_probe.cpp/.h` → `head_aim.cpp/.h` (без зонда), `head_aim_probe_core.h` уходит, общие
  части (опознание игрока, проверки, строки хуков) переезжают в `head_aim_core.h`; `head_aim_core.h` без `raw`,
  `latch`, `minus`/`off`, `stick_comp=off` и разбора угла; `on_foot_hud.cpp`/`on_foot_hud_core.h` без чтения ширины;
  вызовы в `device_hook.cpp`; комментарии `on_foot_aim_eye*.h`/`.cpp`.
- Сборка: `build.bat` (список исходников, гейт `:rig_head_aim_probe_test` убрать, `:rig_head_aim_test` и стенд HUD
  без проверок удалённых вариантов), `edvr\edvr.ini` (блоки ключей), F8 и контракт конфига собираются из ini сами.
- Стенды: `tools\head_aim_probe_test\` удаляется; `tools\head_aim_test\` получает проверки опознания игрока.
- Живой `edvr.ini` игры: строки удалённых ключей убрать через Edit (как в `.45`).
- Спеки: `on-foot-aiming`, `on-foot-hud`, `on-foot-head-aim-probe` (удаляется).
- Риск: кто ставит сборку с ключом по умолчанию, сразу получает прицел головой. Если игра не той версии (не 334925)
  или DLL разные, фича сама стоит в стороне, со строкой в логе, как и раньше.
