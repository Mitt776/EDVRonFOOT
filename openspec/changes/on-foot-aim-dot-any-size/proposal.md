# Точка прицела без оружия при любом размере атласа

## Why

Точку без оружия модуль узнаёт по образцу, снятому при одном размере атласа: 2076x1787 (SteamVR, HMD Quality 0.75,
`.42`). На любом другом размере он сдаётся, и точка видна. С 08.11 Дима летает через Oculus напрямую. Meta-среда просит
картинку чуть меньше, и атлас стал 1868x1608, а при HMD Quality 0.5 — 1245x1072. Во всех полётах после перехода
(`edvr_gfx_20261108_214113`, `_223232`, `_231624`) в логе `the plain dot's pattern is for a 2076x1787 atlas … nothing is
erased`, `hidden=0`: точка у Димы сейчас **видна**. У игроков публичной сборки 0.1.0 размер тоже любой, и у них точка видна
почти у всех.

Хорошая новость из тех же логов: атлас меняется строго пропорционально (1868/2076 = 1608/1787 = 0.900, 1245/2076 =
0.600). Пропорция 1.161 держится, атлас находится, а прямоугольник центра уже считается в долях. Ломается только сам
образец точки.

## What Changes

Два шага, каждый со своей сборкой и полётом.

- **Шаг 1, разведка (ничего не стирает на новых размерах).** На любом размере атласа модуль читает строки центра и
  ищет точку так же, как на 2076. Образец берётся из `.42`, пересчитанный под масштаб атласа (`s` = ширина / 2076):
  окно — прямоугольник центра этого атласа, ожидаемая сумма яркости — по площади, предел пятна — 7·s. Решение и подпись
  пишутся в лог с пометкой «на пробу», а стирает модуль по-прежнему только на 2076x1787. Полёты на 1868 (обычный режим
  Димы) и на 1245 (HMD Quality 0.5) дают настоящие картинки точки для стенда.
- **Шаг 2, стирание на любом размере.** Пороги уточняются по картинкам шага 1, и пересчитанный образец начинает
  стирать на всех размерах. Сверху добавляется **самообучение**: при выходе на ноги, без признака оружия, в центре лежит
  обычная точка (сдвиг сбрасывается, `.59`). Модуль запоминает её как образец для этого размера и дальше ищет и
  узнаёт точку по нему. Пересчитанный образец служит стражем: если модуль выучил что-то непохожее на точку, такой образец
  не принимается.
- На 2076x1787 решение остаётся прежним: образец `.42`, облётанный в `.60`.
- Новых ключей нет. `native_vr_on_foot_aim_dot` (`hide`/`show`), признак оружия, стирание, сводка — без изменений.
  Строка `the plain dot's pattern is for a 2076x1787 atlas…` уходит. Вместо неё — строка «образец для WxH» (масштаб,
  окно, сумма) и строка о выученном образце.

**Не входит:** другие шлемы (Index, Pico, Reverb) и пропорция атласа 1.161. Откуда она берётся и меняется ли с шлемом, не
проверялось. Это отдельная разведка, когда придёт первый issue. Если пропорция другая, атлас не найдётся, и точка
останется видна, как сейчас.

## Capabilities

### New Capabilities

(нет)

### Modified Capabilities

- `on-foot-aim-dot`: меняется «Узнавание обычной точки» (любой размер атласа, пересчитанный образец, самообучение);
  добавляется «Образец точки для размера атласа» (как он получается и какие строки пишет).

## Impact

- Код: `edvr/src/d3d11/aim_dot_core.h` (образец под масштаб, `readCentre`/`readRow` с окном любого размера,
  самообучение, строки), `edvr/src/d3d11/aim_dot.cpp` (снятие стража 2076, окно и высота полосы по прямоугольнику
  центра, образец на атлас, сброс при новом выходе на ноги).
- Стенд: `edvr/tools/aim_dot_test` — пересчёт образца на 1868, 1245 и 2768. После шага 1 добавятся настоящие образцы
  1868 и 1245 из полётов.
- Документы: `docs/research/native-vr-on-foot.md`, `ROADMAP.md`, `edvr/README_EDVRONFOOT.md`, комментарий ключа в
  `edvr/edvr.ini` (там упомянут «2076x1787 interface sheet»).
- Git: ветка `change/on-foot-aim-dot-any-size`, PR в `main`. После полёта и «да» Димы — слияние. Выпуск 0.1.1 —
  только по отдельному «да».
- **Как проверить руками.** Шаг 1: летаешь как обычно (Oculus напрямую), на ногах без оружия, потом с оружием и
  инструментом, потом то же на HMD Quality 0.5. Точка пока видна, это нормально. Я смотрю лог. Шаг 2: те же пункты —
  без оружия точки нет при обоих HMD Quality, с оружием и инструментом прицел виден. План по пунктам в `tasks.md`.
