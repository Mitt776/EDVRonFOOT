# Design

## Context

- Git: одна ветка `master`, 230 коммитов, 61 тег `v0.19.1-edvronfoot.N`, удалённого репозитория нет. Автор всех
  коммитов — Dima с личной почтой. `gh` залогинен как `Mitt776` (id 187125319).
- В истории: имя пользователя Windows `user` в путях (11 файлов в нынешнем дереве, в истории больше; только
  документы заявок). `screenshots/` (3,7 МБ, скриншоты игры 23.10) в историю не попадала никогда — она в
  `.git/info/exclude` (проверено 08.11, задача 1.2); `--invert-paths` остаётся страховкой.
- Уже исключены `.gitignore`: SDK DLSS (`third_party/ngx`, лицензия NVIDIA), сборка `ffx-dx11`, загрузчик OpenXR,
  `build/`, логи, `.claude/`, `reviews/`.
- Установщик есть от EDVR: `build.bat` собирает `edvr-installer.exe` (~72 МБ, сам в себе), `package.bat <версия>`
  вызывает `tools/package_native.py` для VR и для плоского издания. Названия в свойствах файлов задаёт
  `tools/gen_installer_rc.py` («EDVR (unofficial)», «EDVR unofficial patch»).
- Версия в DLL и в логе — `git describe --tags`, поэтому пометка «edvronfoot» в логе (требование `edvr-fork`) живёт в
  имени тега.
- `git filter-repo` не установлен (ставится `pip install git-filter-repo`).

## Goals / Non-Goals

**Goals:**
- Одна переписка истории до первой отправки, проверяемая поиском.
- Установщик и DLL называются EDVRonFOOT, номер выпуска `0.1.0`.
- Порядок работы «заявка — ветка — PR» записан там, где его читает агент (`edvr/AGENTS.md`), и в шаблоне PR.

**Non-Goals:**
- Автопроверки на GitHub (Actions) — отдельная заявка: сборке нужны MSVC и SDK DLSS, это своя работа.
- Подпись установщика сертификатом — Windows будет предупреждать (SmartScreen), README об этом говорит.
- Поддержка других сборок игры, кроме той, что знает мод.
- Перевод внутренних документов (исследования, заявки) на английский.

## Decisions

**1. Переписка истории — `git filter-repo`, один проход, после резервной копии.**
- Резервная копия: `git clone --mirror` всего репозитория в папку рядом (вне проекта) плюс архив рабочей папки.
- Один запуск с `--mailmap` (личная почта → `187125319+Mitt776@users.noreply.github.com`), `--invert-paths --path
  screenshots/` и `--replace-text` (`user` → `user`). Теги переписываются вместе с коммитами.
- Ветка `master` → `main` до переписки.
- Отвергнуто: *BFG* — нужна Java, а почту он не меняет. *`git filter-branch`* — устарел, медленный, легко ошибиться.
  *Новый репозиторий из одного коммита* — теряется история, а она ценна (облёты, решения).

**2. Эта заявка идёт прямо в `main`.** Удалённого репозитория ещё нет, PR открыть некуда. Порядок «ветка — PR»
вступает в силу со следующей заявки. Переписка истории — первой задачей, чтобы остальная работа лежала уже на новой
истории.

**3. Теги `edvronfoot-vX.Y.Z`.** `git describe` даёт в лог `edvronfoot-v0.1.0`, пометка EDVRonFOOT сохраняется без
правок кода. Отвергнуто: *`v0.1.0`* — лог перестанет говорить «edvronfoot» (нарушит `edvr-fork`), пришлось бы
дописывать название в коде; *оставить `v0.19.1-edvronfoot.N`* — длинно и путает с версией EDVR.

**4. Установщик — переименование, не новый.** `gen_installer_rc.py`: CompanyName/ProductName/описания → EDVRonFOOT
(«EDVRonFOOT — native VR on foot for Elite Dangerous, based on EDVR»), имя файла установщика и архива —
`EDVRonFOOT-<версия>`. Плоское издание в релиз не кладём (`package.bat` получает режим только VR или релизный скрипт
зовёт только VR-упаковку). Отвергнуто: *свой установщик с нуля* — тот уже умеет резервные копии, починку, удаление и
проверку сборки игры, с тестами.

**5. README.** Корневой `README.md` (EN) и `README.ru.md` (RU) — для игроков; `edvr/README_EDVRONFOOT.md` остаётся
внутренним справочником на русском. Скриншоты для README — не из удалённой папки, а новые, по желанию Димы, позже.

**6. Почта для новых коммитов.** `git config user.email 187125319+Mitt776@users.noreply.github.com` в этом репозитории.

## Risks / Trade-offs

- [Переписка истории сломает что-то в репозитории] → резервная копия до запуска; после — `git fsck`, сравнение
  дерева `main` с деревом до переписки (кроме `screenshots/` и замен `user`), полная сборка.
- [Замена `user` заденет код] → перед заменой поиск, где встречается; в коде и бинарных файлах не встречается —
  проверить; если встретится — исключить.
- [В истории окажется ключ или токен] → поиск по всем версиям файлов на типовые признаки ключей перед отправкой.
- [Хеши коммитов в документах (`6f335bb`, `cc31471` в заявках и исследовании) устареют] → теги переживают переписку;
  в README_EDVRONFOOT отмечается, что старые хеши в журналах — до 08.11.2026, искать по тегу.
- [DLL DLSS в установщике] → оригинальный EDVR распространяет её так же, с уведомлениями NVIDIA; файлы уведомлений
  остаются в архиве.
- [После патча игры мод у всех перестаёт запускаться] → README говорит об этом прямо и как временно отключить мод.

## Migration Plan

1. Резервная копия → `master`→`main` → `filter-repo` → проверки.
2. Правки установщика, README, AGENTS, шаблон PR → полная сборка → тег `edvronfoot-v0.1.0` → архив релиза → установка
   и удаление на ПК Димы.
3. С «да» Димы: `gh repo create Mitt776/EDVRonFOOT --public`, отправка `main` и тегов, релиз.

Откат до публикации: вернуть резервную копию (`git clone` из зеркала). После публикации: репозиторий можно сделать
приватным или удалить в настройках GitHub (уже скачанное у людей останется).
