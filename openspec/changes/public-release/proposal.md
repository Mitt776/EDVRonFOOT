# Публичный репозиторий EDVRonFOOT и установщик для всех

## Why

EDVRonFOOT задумывался как личный мод, но работает: VR на ногах, прицел головой, панели, точка прицела. Дима решил
(08.11) выложить его на GitHub публично, с установщиком для любого игрока, и дальше вести разработку через GitHub:
ветка и pull request на каждую заявку. Сейчас у проекта нет удалённого репозитория, в истории личная почта и
скриншоты, установщик и версии называются как у оригинального EDVR.

## What Changes

- **История перед первой отправкой (один раз, локально, с резервной копией):**
  - ветка `master` становится `main`;
  - почта во всех коммитах и тегах заменяется на адрес GitHub noreply аккаунта `Mitt776`;
  - папка `screenshots/` удаляется из всей истории;
  - путь с именем пользователя Windows в текстах заменяется на нейтральный.
  - **BREAKING** для локальных клонов: хеши всех коммитов меняются (клон один — этот).
- **Версии:** своя нумерация с `0.1.0`. Теги `edvronfoot-vX.Y.Z`, поэтому строка версии в логе по-прежнему говорит
  «edvronfoot». Старые теги `v0.19.1-edvronfoot.N` остаются историей.
- **Установщик:** готовый установщик EDVR (`edvr-installer.exe`) получает имя, описание и версию EDVRonFOOT. Релиз —
  один архив `EDVRonFOOT-<версия>.zip` с установщиком; плоское издание EDVR (`flat`) в релиз не входит.
- **Витрина:** `README.md` на английском и `README.ru.md` на русском — что это, что умеет на ногах, что нужно (шлем,
  среда OpenXR, сборка игры), установка и удаление, привязка к сборке игры, благодарность автору EDVR. `LICENSE`
  (MIT, автор оригинала) и `UPSTREAM.md` остаются.
- **Публикация (только с отдельным «да» Димы):** публичный репозиторий `Mitt776/EDVRonFOOT`, отправка `main` и тегов,
  первый релиз `EDVRonFOOT 0.1.0` с архивом установщика.
- **Порядок работы через GitHub:** заявка = ветка = pull request; облёт до слияния; архив заявки в том же PR; шаблон
  PR. Правило оригинала «solo project, no pull requests» в `edvr/AGENTS.md` заменяется.
- Автопроверки на GitHub (сборка и тесты на каждый PR) — не здесь, отдельной заявкой.

## Capabilities

### New Capabilities

- `release-distribution`: как EDVRonFOOT выпускается для людей — номер версии, архив релиза с установщиком, что
  показывает установщик, главная страница репозитория на двух языках, что в репозиторий не попадает.
- `development-workflow`: как идёт работа через GitHub — ветка и pull request на заявку, облёт до слияния, архив
  заявки, шаблон PR, адрес почты в коммитах.

### Modified Capabilities

(нет: требования `edvr-fork` — происхождение, сборка, установка, пометка EDVRonFOOT в логе — сохраняются)

## Impact

- История git целиком (переписывается), ветка `main`, теги.
- `edvr/tools/gen_installer_rc.py` (имя и описание в установщике и DLL), `edvr/tools/package_native.py` и
  `edvr/package.bat` (архив релиза), `edvr/build.bat` (только если понадобится для версии).
- Новые файлы: `README.md`, `README.ru.md` в корне, `.github/pull_request_template.md`; правки `edvr/AGENTS.md`,
  `edvr/README_EDVRONFOOT.md`, `.gitignore`.
- Внешнее: репозиторий на GitHub и релиз — только после «да» Димы на шаге публикации.
- Как проверить руками: установщик из архива ставится в папку игры и удаляется (игра с ним стартует, VR на ногах как в
  `.61`); на странице репозитория README на двух языках; в истории нет личной почты и скриншотов (проверка в задачах).
